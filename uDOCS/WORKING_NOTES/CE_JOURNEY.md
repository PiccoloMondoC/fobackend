### DEVELOPMENT JOURNEY

I don't think we should rush this, but I doubt that we would need an Explore page.  No Explore, no View All. We need a Home page, a Search Results page, and an Item Detail page

The Home page should be put to more strategic use than we've able to imagine so far. Sponsored items, recommendations.

What would you say/recommend concerning this?


# I agree. **Home, Search Results, and Item Detail** give us a clearer consumer journey. A category selection can open Search Results filtered to that category; it doesn’t require a separate Explore page or “View all.”

>Home should help people discover something worth their attention, with several purposeful sections:

- **Sponsored offerings:** clearly labelled placements within a bounded feature area.
- **Recommended for you:** eventually informed by explicit interests, watched offerings and followed merchants. Until that infrastructure exists, use an honestly labelled general selection.
- **From merchants you follow:** new offerings from businesses the consumer already cares about.
- **Recently added:** a straightforward route to fresh discoveries.
- **Continue exploring:** offerings the consumer recently viewed, where appropriate privacy controls permit.

These are possible modules, not an instruction to build five empty sections now. With one offering, Home should remain compact and attractive. As inventory and consumer participation grow, useful modules become available.

I’d also make the introductory copy less dominant for returning visitors. Home’s enduring value should be what it helps them discover, rather than repeatedly explaining the platform.

Administrators should govern supported placement choices, section availability and introductory wording. Recommendations must reflect capabilities we actually have; sponsorship needs a proper selection and disclosure mechanism before commercial use.

**My recommendation is to settle Home’s composition and the purpose of each initial section before another coding pass.** The correction I just delivered is too narrow to establish that direction by itself.


# How many sponsored items should we allow on the Home page?


I recommend **up to three sponsored offerings on Home**, within one compact section near the top.

- **Desktop:** show all three together.
- **Mobile:** stack them, without autoplay or automatic rotation.
- Clearly label each offering **Sponsored**.
- Show fewer when fewer qualify; never fill unused places with duplicates.

Three is a ceiling, not a target. Sponsored placements should remain a minority as Home develops.

Make that limit **Admin-configurable within engineering-defined bounds**. For our current acceptance testing, one demonstration placement is sufficient.
